# Arya Medicine – website

Static bilingual (Hindi default, English at `/en/`) information site for
Arya Medicine, veterinary medicine agency, Husain Chowk, Supaul, Bihar.

- `index.html` – Hindi home page
- `en/index.html` – English home page
- `style.css` – shared styles
- `assets/cover.html` – source for the Google Business Profile cover image (render with headless Chrome at 1024×576)
- `sitemap.xml`, `robots.txt` – SEO

Hosted on GitHub Pages. To attach the custom domain, add a `CNAME` file
containing the domain and point DNS at GitHub Pages.
